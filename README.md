
# Simple Interest Calculator

A lightweight Bash script project created as part of the IBM / NAVTTC Git & GitHub final lab assignment.

## Project Description

This repository contains a simple shell script (`simple-interest.sh`) that calculates the Simple Interest and total payable amount based on user inputs:
- **Principal Amount**
- **Annual Rate of Interest (%)**
- **Time Period (in years)**

## Formula Used

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- $P$ = Principal Amount
- $R$ = Annual Rate of Interest
- $T$ = Time Period in years
